CENTERMINT / 計算機とガイド

カードのセンタリング計算機

左右・上下の余白を入力してセンタリング比率を計算。向きを保った図で確認できる無料のブラウザー用ツールです。

同じ単位で測った四辺の幅を入力します。ピクセルでも mm でも構いません。このツールは比率の計算用で、写真から枠を検出するものではありません。

0 以上の数値を入力し、左右・上下それぞれの合計を 0 より大きくしてください。

余白の比率を示すイメージ

余白の幅から比率を求める

左の割合 = 左 ÷（左 + 右）× 100。上の割合 = 上 ÷（上 + 下）× 100。反対側は残りの割合です。左 3 mm、右 2 mm なら 60.0 / 40.0。左右を入れ替えると 40.0 / 60.0 ですが、ずれの程度は同じです。

丸い角を避け、対応する位置で両側の幅を測ります。表と裏は別々に測ってください。斜めの写真は見かけの余白が変わるので、視点を整えてから測ります。図は比率の説明用で、特定のカードを再現したものではありません。

小数 1 桁の表示は測定精度を保証しません。この計算機は鑑定点数を判定しません。
